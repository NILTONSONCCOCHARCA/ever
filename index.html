Lo que aprenderás haciendo

Cada ciclo termina con un proyecto real. Practicas en laboratorio, no solo en pizarra.

Programación

Lógica, Python, Java y JavaScript. Del primer algoritmo a una aplicación completa.

Bases de datos

Diseña, consulta y protege la información de un negocio con SQL.

Redes y soporte

Arma redes, repara equipos y atiende a usuarios con criterio técnico.

Desarrollo web

Crea páginas y sistemas para tiendas, colegios y emprendimientos locales.

Al terminar podrás

  • Desarrollar sistemas y sitios web para empresas e instituciones.
  • Instalar, configurar y proteger redes de computadoras.
  • Administrar bases de datos y generar reportes.
  • Dar soporte técnico y mantenimiento a equipos y software.
  • Emprender tu propio negocio de servicios informáticos.

Dónde puedes trabajar

  • Empresas de software y agencias digitales.
  • Municipalidades, colegios, clínicas y bancos.
  • Hoteles y agencias de turismo.
  • Áreas de TI de cualquier organización.
  • Como independiente o freelancer.
